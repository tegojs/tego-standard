# 完整分页结果计划

沿用已批准的访问控制设计及测试驱动流程，在当前功能分支增加内部完整分页结果，不注册业务资源、不修改业务配置。

## 契约

`listPageFromParams` 返回核心主库分页形状 `{ rows, count, page, pageSize, totalPage }`。列表与总数复用一次根读取计划、同一份权限快照和请求筛选；总数不受分页、关联展开及仅排序用的目标影响，不重复计数根记录。沿用已有每页、偏移、关联深度与响应上限。没有匹配时 count/totalPage 为 0；超出末页时 rows 为空但 count 保留。事务从服务端独立传入，贯穿列表、计数及展开；无事务时不承诺跨 SQL 的同一时刻数据快照。

在 `AccessReadService.page` 增加可信内部计数选项，计数复用排序计划提供的无排序根查询，避免遗漏筛选或带上仅排序绑定。普通分页使用 `listWithCount`，不读取隐藏配对键、不施加关联拼接的主键长度限制；两条路径共用计数及生命周期检查。`AccessExpandedReadService` 在同一已授权组装操作内传递根总数，旧 list/get 返回值与查询次数保持不变。入口 selected 内部返回统一结果，由旧公开方法继续返回数组或单条，新分页方法单独返回分页结构。
