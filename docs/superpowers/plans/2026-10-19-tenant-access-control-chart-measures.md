# 图表多统计项实施计划

**目标：** 内部图表适配支持 1–10 个根字段统计项，同一条 SQL 计算全部统计，统一应用角色、G/V 和请求条件。

**架构：** `aggregate-measures.ts` 捕获明确的字段、五种方法和内部 distinct；`reads.ts` 增加 `aggregateMany`，复用现有读取计划和分组 SQL 执行器。原有标量和单项分组接口保留返回结构。`chart-params.ts` 校验全部输出别名，将排序定位到具体统计项索引；`entry-reads.ts` 保留单项路径，多项委托批量查询。

**边界：** 根物理字段；零至三个维度；统计项别名不能重复，重复统计字段可用不同别名区分；最多 13 个排序项。所有字段独立授权，任一非法则 SQL 前拒绝，不返回部分结果。标量空集合返回一行（count 为 0，其余为 null）；分组空集合返回空数组。组数上限继续整体拒绝。事务、日期、生命周期与历史数据读取规则沿用现有实现。仍不支持关联统计字段、日期格式化、SQL 或客户端 distinct，不改业务入口、核心或依赖。

- [x] 增加失败测试：多项标量/分组、五方法与 NULL、分数平均值、每项字段权限、角色与关联筛选、事务日期、排序别名与索引、输入快照、上限及 SQL 查询数量。
- [x] 新增严格的批量统计输入捕获；将分组 SQL 抽为共用执行器，增加批量计划和逐项字段验证，保留原单项行为。
- [x] 扩展图表参数和输出映射，允许多项并限定总规模；排序在权限回调前定位到明确统计项。
- [x] SQLite 红绿验证、随机专用 PostgreSQL/SQLite 图表聚焦和根/关联回归；严格类型、lint、格式、租户包构建及独立审查通过后签名原子提交。

验证：`node .tmp/tenant-access-verify.cjs --chart-focused`、`node .tmp/tenant-access-verify.cjs --numeric-aggregate`、`node .tmp/tenant-sort-types.cjs`、`pnpm exec tegod build @tachybase/module-tenant`。所有数据库测试仅使用独立随机本地测试库。

## 验证记录

- 首轮 SQLite 9 项多统计项测试因数组上限仍为 1 失败；实现后 SQLite 图表 36 项通过。
- 最终 SQLite / 随机专用 PostgreSQL 图表聚焦 72 项通过（27.09 秒）；根读取、目标外键关联及多对多读取完整回归 824 项通过（238.10 秒），包括批量输入描述符、distinct、排序索引和权限前快照测试。所有随机专用测试库已删除并确认不存在。
- 严格 TypeScript 0 项诊断、oxlint 0 项错误/警告、Prettier、差异检查和租户包构建通过。独立审查未发现阻断项，审查者另运行 SQLite 多项统计聚焦 13 项通过。
- 保留原单项图表和单项分组的返回结构；多项统计字段共用同一 SQL。核心、依赖、业务数据和业务配置均未修改，真实图表入口尚未接入。
