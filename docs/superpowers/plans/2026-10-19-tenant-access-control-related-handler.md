# 普通读取处理器的关联权限

目标：允许内部普通读取处理器通过服务端回调，逐路径接收目标表已经完成核心 ACL 的列表上下文，交给现有统一读取器执行关联筛选、排序和展开。不注册业务路由，不自行重做 ACL，不变更核心或依赖。

回调接收目标集合、本次关联路径和冻结的请求身份。每个目标必须来自相同配置数据库，实际动作是该目标表的普通 `list`，角色与本次可信身份相同。只接受无用户查询条件的最终列表决策；不能将带定位或筛选条件的详情/列表授权扩成整张目标表的权限。根权限不能复用于关联；缺少目标决策仍拒绝。每跳字段、角色条件和 G/V，以及路径、集合身份与生命周期继续由既有读取器统一检查。关联最终上下文由可信调用者通过现有授权链提供，本阶段不增加虚拟 HTTP 请求或第二套角色求值。
