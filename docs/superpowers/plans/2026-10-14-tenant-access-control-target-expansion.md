# 一对多和一对一批量展开计划

沿用已批准设计，在 `feat/tenant-access-control` 新增内部 `AccessTargetForeignKeyExpansionService`，不接入现有业务、不改业务数据或依赖。

一页最多 1000 个明确来源主键，来源分别满足 ACL 与 G/V；任一来源不可读则整体拒绝。一次来源查询加一次目标查询，目标按真实外键、关联 scope、目标 ACL 与 G/V 过滤。HasMany 返回已授权字段组成的数组，HasOne 返回单条或 `null`；隐藏目标不会删掉来源。目标按主键稳定排序，内部主键/外键不默认返回，虚拟字段及 getter 不作为响应投影。

不支持每条来源的自定义分页、排序或 `_` 占位符。单次最多展开 10000 个可读目标，超限整体拒绝，不静默截断。HasOne 出现多个可读目标时明确拒绝。事务保留为活跃数据库对象，其他输入在 await 前复制。

复用 BelongsTo 的字段与元数据检查，提取共同的内部帮助函数。元数据快照只检查来源、目标及 G/V 条件实际引用的关联、模型和中间表，避免遍历无关业务表；相关元数据改变时失败关闭。
